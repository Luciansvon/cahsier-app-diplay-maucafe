# Coffee Queue Display

Workspace untuk demo sistem antrean dan digital signage outlet kopi.

Target demo:

- HP/tablet sebagai panel admin.
- Laptop sebagai server lokal dan layar pelanggan.
- Smart TV dapat menggantikan layar laptop bila berada pada jaringan yang sama.
- Hosting belum diperlukan pada tahap demo.

Status: workspace dan aturan repo sudah disiapkan; aplikasi belum dibuat.

⚡ ARSITEKTUR TERPADU

⚖️ PERBANDINGAN ARSITEKTUR

Perbandingan: Local vs Cloud Online

Pahami perbedaan mendasar cara kerja, kebutuhan perangkat, dan batas akses sebelum memilih paket.

STARTER LOCAL / OFFLINE Wi-Fi Toko
  • Lokasi Server: Mini PC / Laptop di dalam toko (wajib menyala saat toko buka).
  • Internet Toko: TIDAK WAJIB untuk transaksi lokal kasir & TV antrean.
  • Akses Dashboard Owner: Hanya dari Wi-Fi toko secara default. Tidak bisa dari rumah.
  • Kelebihan: Biaya awal hemat, tanpa biaya server tahunan.
  • Kekurangan: Butuh komputer server di toko, remote terbatas.
BUSINESS CLOUD / MULTI-OUTLET Online Internet
  • Lokasi Server: Berada di cloud server internet terpusat.
  • Internet Toko: WAJIB tersedia agar Kasir, TV, & Owner terhubung.
  • Akses Dashboard Owner: Bisa dari mana saja (rumah/luar kota) via internet.
  • Kelebihan: Toko tak butuh laptop server, praktis multi-cabang.
  • Kekurangan: Tergantung internet, ada biaya cloud tahunan.

🔍 SKENARIO OPERASIONAL

Skenario Nyata Operasional Outlet

Bagaimana sistem merespons berbagai kondisi riil di toko?

Skenario 1: Owner di rumah ingin mengecek omzet harian

LOCAL: Tidak dapat diakses dari luar toko secara default. • CLOUD / MULTI: Bisa dibuka kapan saja dari HP/Laptop via internet.

Skenario 2: Internet Wi-Fi provider di toko tiba-tiba mati

LOCAL: Kasir & TV Antrean tetap berjalan lancar via jaringan router lokal. • CLOUD: Terhenti sementara sampai koneksi internet toko kembali terhubung.

Skenario 3: Komputer Mini PC server di toko mati/rusak

LOCAL: Sistem lokal terhenti sampai server dinyalakan. • CLOUD: Tidak terpengaruh karena tidak menggunakan server komputer lokal toko.

Skenario 4: Membuka cabang/outlet baru di lokasi lain

LOCAL: Membutuhkan pengadaan server lokal baru. • MULTI-OUTLET: Cabang baru langsung ditambahkan ke dalam server terpusat yang sama.
